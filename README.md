# Quiz Application 🎯

A responsive Quiz Application built using HTML, CSS, and JavaScript.  
It allows users to answer multiple-choice questions, navigate between questions, track progress, complete the quiz within a time limit, and view their final score.

## 🚀 Features

- Multiple-choice questions
- Question display
- Next and Previous navigation
- Countdown timer
- Progress bar
- Answer validation
- Automatic score calculation
- Final result display
- Restart quiz functionality
- Local Storage for saving answers
- Responsive design for mobile and desktop
- Hover and focus effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
